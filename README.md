# Diabetes Prediction using Machine Learning

Predicts whether a patient is diabetic using health metrics (Glucose, BMI, Age, Insulin, etc.)
from the Pima Indians Diabetes dataset.

## What it does
- Exploratory data analysis (distributions, correlation heatmap, feature importance)
- Trained and compared 4 models: Logistic Regression, Random Forest, SVM, KNN
- Evaluated using classification report and ROC-AUC
- Final model (Logistic Regression) saved as a .pkl file

## Tech stack
Python, pandas, scikit-learn, seaborn, matplotlib
